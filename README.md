# 線控飛機油門控制器 韌體更新檔

這個專案只放「線控飛機油門控制器」(ESP32-C3)的**韌體更新檔**,不放原始碼。

## 必要硬體:起飛安全開關(2026.09.14.7 起)

微動開關一端接 **GPIO21**,一端接 **GND**(建議串一顆 1kΩ 電阻)。推飛機、網頁「開始起飛程序」、上電後直接倒數都照常開始,但**要按下安全開關才會開始倒數**;起飛程序中按過一次就記住,倒數與飛行中放開不影響。沒接開關、線斷掉,就不會倒數,馬達不轉。等開關時狀態燈慢閃,網頁「監看」頁會顯示開關狀態。

起飛程序開始後超過**安全開關等待上限**(設定頁,出廠 3 分鐘)沒按,就自動取消。

## 感測器腳位(2026.09.14.12 起)

MPU6050 的 SDA 接 **GPIO5**、SCL 接 **GPIO6**。

## 怎麼更新(建議)

1. 板子連上家用 WiFi(要能上網)。
2. 手機或電腦打開板子的網頁,到「系統」頁的「韌體更新」。
3. 按「檢查更新」,看完更新說明後按「更新到 …」(按兩下確認)。只有這裡的版本比板子上的新,才會出現更新按鈕。
4. 板子會自己下載、檢查、安裝,完成後自動重新開機。
5. 網頁**保持開著**,板子重開後網頁會自動確認新韌體(不用按按鈕)。

### 安全保護

- 只有待機時能更新,更新中不能起飛。
- 下載的檔案大小或檢查碼不對,就放棄更新,目前的韌體不變。
- 板子重開後,開著的網頁會自動確認新韌體(不用按按鈕);新韌體連上 WiFi 後 1 分鐘內沒有網頁連上(例如新韌體連不上 WiFi),會**自動退回舊版**。確認前不能起飛。
  為什麼要網頁確認:板子自己只知道開機了、WiFi 連上了;由網頁確認,才能保證新韌體更新完之後你還控制得到板子。
- **更新時請保持網頁開著**:手機螢幕關掉或切到別的 App 時網頁會暫停,超過 1 分鐘才回來會退回舊版(板子安全,再更新一次即可)。
- 更新完重新開機後不會自己倒數;要飛請拔掉電池再接上。
- 更新會重新開機,沒儲存的設定會不見,請先儲存。

## 手動更新

如果板子沒辦法上網,可以在電腦到 [Releases](https://github.com/licni/ESP32lineplane-firmware/releases) 下載要的版本的 `firmware-版本.bin`,再到板子網頁「系統 → 韌體更新 → 手動上傳韌體檔」上傳。保護方式相同。
## 每個版本改了什麼

**每天只留當天最新的一版**,當天的修改都合併在那一版的說明裡。

- [更新紀錄 CHANGELOG.md](CHANGELOG.md):每天的修改內容,最新在最上面。
- [Releases](https://github.com/licni/ESP32lineplane-firmware/releases):每天最新版的說明與韌體檔下載。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `manifest.json` | 最新版本資訊(版本、大小、SHA-256 檢查碼、韌體檔位置、更新說明),板子檢查更新時讀這個 |
| `CHANGELOG.md` | 更新紀錄 |
| `firmware/` | 韌體檔資料夾,只留最近 3 天(每天一個);更早的在 Releases 下載 |

請不要改檔名或搬動檔案,板子是依照 `manifest.json` 裡寫的位置下載。
